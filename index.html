BeagleBone Black edge router

Embedded Linux and networking project, 2026

A BeagleBone Black turned into a working edge router, built from the bootloader up. It boots my own U-Boot and Linux 6.18 kernel over TFTP, routes and NATs between LAN and WAN behind an nftables firewall with separate office and guest VLANs, and runs OSPF and BGP with FRR. I added a netfilter kernel module, eBPF/XDP packet filters, a C tool that talks rtnetlink and a Rust tool cross-compiled for ARM.

I profiled the single 1 GHz core with perf: dropping a packet flood in XDP cost about 10 µs per packet against 22 µs in nftables, and one nftables set replaced 500 linear rules at almost no cost. The firewall is tested in Linux network namespaces and on the real board, with CI on every push, a lintian-checked Debian package and DKMS for the kernel module.

Built with U-Boot, Linux kernel, C, Rust, Python and pytest, eBPF/XDP, nftables, FRR, perf, GitHub Actions, Debian packaging

Three-level NPC solar inverter with GaN devices

Single-phase solar PV inverter, university project

A high-efficiency neutral-point-clamped inverter built on GaN power devices. I derived a cascaded dual-loop PI controller, validated it in PLECS, and wrote the full firmware stack on a TI C2000: CLA-based real-time control, a state machine, fault detection and SPI communication.

Early boards suffered from gate-drive noise, Miller-effect coupling and ground bounce. I traced each cause on the bench, fixed them with a full PCB redesign, and confirmed the cooling design with thermal simulation.

Built with TI C2000 and CLA, C, PLECS, Fusion 360, thermal simulation

Microinverter for CdTe/CdS solar modules

Final-year project, University of Peradeniya

An off-grid microinverter designed for CdTe/CdS solar modules manufactured in Sri Lanka. It combines the inverter, a battery with a battery management system and a load-tracking algorithm into one compact unit mounted with the module, to make clean energy easier to access.

Built with MATLAB/Simulink, PSIM, PLECS, Altium Designer, battery management, thermal design

An interleaved push-pull DC-DC converter feeding a full-bridge inverter stage. I designed and optimised the transformer and inductors, selected the power and control ICs, drew the complete schematic, and validated converter and control behaviour through simulation.

Built with PLECS, TINA-TI, magnetics design, schematic and PCB design

Industrial automation project

Monitors and controls a conveyor automatically when a package is detected. An ESP32 acts as both the data-acquisition device and an OPC-UA server, communicating over Wi-Fi with an Ignition SCADA client that shows live data and controls on a PC.

Built with ESP32, ESP-IDF, C/C++, OPC-UA, Ignition SCADA
